# Análisis de hábitos de consumo e identificación de problemas en las órdenes
Identificación de patrones de recompra (las bebidas superan el 70% de retención), detección de picos de pedidos a los 7 días y a las 10:00-15:00 horas, y corrección de fallas de registro en un universo de 149,626 usuarios únicos.
